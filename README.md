# 🎓 EduAssist AI – Academic Tracking & Student Support Platform

## 📖 Overview

EduAssist AI is a role-based academic management platform developed using **React.js** and **Firebase Firestore**. The platform enables students to manage assignments, receive AI-inspired reminders, and submit anonymous complaints, while providing faculty members with tools to monitor and resolve student issues through a dedicated dashboard.

---

## ✨ Features

### 👨‍🎓 Student Module

* Secure role-based login
* Add and manage assignments
* AI Smart Reminder for pending assignments
* AI Workload Analysis
* Submit anonymous complaints
* Track complaint status
* Personalized student dashboard

### 👨‍🏫 Faculty Module

* Faculty login
* View all student complaints
* Mark complaints as resolved
* Complaint monitoring dashboard

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/EduAssist-AI.git
```

### Navigate to the project

```bash
cd eduassist-ai
```

### Install dependencies

```bash
npm install
```

### Run the application

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```
